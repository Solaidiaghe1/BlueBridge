## 🔧 TROUBLESHOOTING

### "Too many open files" error?
**Fix:** The server has been restarted in tunnel mode. If it happens again:
```bash
pkill -f "expo start"
npx expo start --tunnel
```

### QR code won't scan?
**Fix:** 
- Ensure phone and computer are on same WiFi
- Try pressing `w` for web version
- Try tunnel mode: `npx expo start --tunnel`

### App won't load?
**Fix:**
- Press `r` to reload
- Check terminal for errors
- Restart server with `Ctrl+C` then `npm start`
