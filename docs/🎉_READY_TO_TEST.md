## 🐛 TROUBLESHOOTING

### App won't load?
- Press `r` to reload
- Check terminal for errors
- Try `Ctrl+C` and restart with `npm start`

### QR code won't scan?
- Ensure phone and computer on same WiFi
- Try pressing `w` for web version
- Check your phone's camera permissions

### Still seeing errors?
- Check `ISSUE_RESOLVED.md` for solutions
- Try `npm start -- --clear` to clear cache
- Make sure you're in the BlueBridge directory
